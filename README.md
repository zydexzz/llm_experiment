# llm_experiment

Эксперимент: сколько токенов занимает **один и тот же текст** на английском, русском и казахском (кириллица и латиница) у разных токенизаторов.

- **tiktoken** (OpenAI): `cl100k_base` (GPT-4 / GPT-3.5) и `o200k_base` (GPT-4o и новее) — считаются локально.
- **Claude**: официальный метод `client.messages.count_tokens` для моделей `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`, `claude-fable-5-2`.

Текст — три предложения о токенах (30–41 слово), в четырёх вариантах: английский, русский, казахский (кириллица) и казахский (латиница, транслитерация по таблице 2021 г.).

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Ключ Anthropic API

Для подсчёта токенов Claude нужен ключ. Он хранится в файле `.env`, который **не попадает в git** (он есть в `.gitignore`).

```bash
copy .env.example .env
```

Откройте `.env` и вставьте ключ после знака `=`:

```
ANTHROPIC_API_KEY=ваш_ключ
```

Не храните ключ в других файлах (например, `api-key.txt`): git их не игнорирует. Если ключа нет, скрипт всё равно работает — считает только tiktoken и подсказывает, как добавить ключ.

## Запуск

```bash
python token_count.py
```

Скрипт печатает тексты, подробную таблицу для каждого токенизатора и две сводные таблицы. Запросов к API около 20; `count_tokens` не генерирует текст, но на него действуют лимиты числа запросов.

## Результаты

Запуск от 10.11.2026. Для Claude из каждого числа вычтена служебная добавка запроса (8 токенов, подробности в оговорках). Четыре модели Claude дали **одинаковые** числа, поэтому они объединены в один столбец.

Число токенов:

| Текст | tiktoken `cl100k_base` | tiktoken `o200k_base` | Claude (Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.2) |
|---|---:|---:|---:|
| Английский | 45 | 45 | 62 |
| Русский | 105 | 61 | 92 |
| Казахский (кириллица) | 181 | 73 | 130 |
| Казахский (латиница) | 108 | 94 | 128 |

Во сколько раз больше токенов, чем в английском варианте (у того же токенизатора):

| Текст | `cl100k_base` | `o200k_base` | Claude |
|---|---:|---:|---:|
| Английский | 1.00 | 1.00 | 1.00 |
| Русский | 2.33 | 1.36 | 1.48 |
| Казахский (кириллица) | 4.02 | 1.62 | 2.10 |
| Казахский (латиница) | 2.40 | 2.09 | 2.06 |

Символов на один токен:

| Текст | `cl100k_base` | `o200k_base` | Claude |
|---|---:|---:|---:|
| Английский | 5.67 | 5.67 | 4.11 |
| Русский | 2.49 | 4.28 | 2.84 |
| Казахский (кириллица) | 1.30 | 3.22 | 1.81 |
| Казахский (латиница) | 2.18 | 2.50 | 1.84 |

## Выводы

1. **Английский везде самый «экономный».** У Claude русский текст занимает в 1,48 раза больше токенов, чем английский, а казахский — примерно вдвое больше (в 2,10 раза на кириллице и в 2,06 раза на латинице).
2. **У Claude кириллица и латиница для казахского почти не различаются:** 130 против 128 токенов (латиница на 1,5% короче). У tiktoken разница заметная и противоположная в двух кодировках: в `cl100k_base` латиница короче кириллицы на 40% (108 против 181), в `o200k_base` — длиннее на 29% (94 против 73).
3. **Все четыре проверенные модели Claude дали одинаковые числа** на всех четырёх текстах. Скорее всего, у них общий токенизатор, но это не проверялось на других текстах и других моделях. Для этого образца выбор модели на число токенов не влияет.
4. **Claude против OpenAI.** На английском Claude даёт больше токенов, чем обе кодировки tiktoken (62 против 45, на 38% больше). На кириллице Claude лучше старой `cl100k_base` (русский 92 против 105, казахский 130 против 181), но хуже новой `o200k_base` (92 против 61 и 130 против 73). Для казахской латиницы Claude уступает обеим кодировкам (128 против 108 и 94).
5. **Новая кодировка OpenAI сильно улучшила кириллицу:** переход с `cl100k_base` на `o200k_base` сократил русский текст с 105 до 61 токена, казахский на кириллице — со 181 до 73. На английском разницы нет (45 и 45).

## Оговорки

- **Это один короткий образец**, а не статистика. Выводы — ориентир; числа на других текстах (особенно с кодом, числами, длинными словами) будут другими.
- **Казахский текст составлен с помощью ИИ и не проверялся носителем языка.** Слов в вариантах разное количество (41, 35, 30, 30), поэтому «токенов на слово» между языками сравнивать нельзя — для этого лучше смотреть на отношение к английскому или на «символов на токен».
- **Казахская латиница получена автоматической транслитерацией** по таблице 2021 г. ([Википедия](https://en.wikipedia.org/wiki/Kazakh_alphabets), апрельская редакция с `ñ`). У казахской латиницы было несколько редакций (2017, 2018, 2021); для другой редакции (например, с апострофами) числа для латиницы были бы другими. Таблицу я сверял по Википедии, а не по официальному документу.
- **Служебная добавка вычтена приближённо.** `count_tokens` считает токены всего запроса, включая оформление сообщения. Добавка (8 токенов) определена как разница для запроса из одного символа «.» и 1 токена, то есть возможна ошибка в ±1 токен. Абсолютные числа Claude — это число токенов самого текста, а не стоимость запроса.
- **tiktoken — токенизатор OpenAI**, по нему нельзя оценивать токены Claude. Для Claude используйте `count_tokens`.
- Список моделей и числа актуальны на дату запуска (10.11.2026); токенизаторы моделей могут измениться.
